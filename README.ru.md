RotationCore следит за вашей специализацией, талантами, ресурсами и целью и
подсвечивает следующую способность. Аддон **модульный** — небольшое ядро плюс
отдельный LoadOnDemand-модуль на каждый класс — и рассчитан на надёжность: без
небезопасного API, без тайнта, без внешних зависимостей сверх вшитых библиотек.

> **Коротко:** 10 классов · 29 спеков · 12 локалей · статическая проверка, CI и
> автоматические релизы по тегу.

## Быстрый старт

1. Скачайте свежий `RotationCore-<version>.zip` из
   [**Releases**](https://github.com/Hijackery/RotationCore/releases).
2. Распакуйте в `World of Warcraft/Interface/AddOns/` так, чтобы папки легли как
   `AddOns/RotationCore` и `AddOns/RotationCore_<Class>`.
3. Включите **«Загружать устаревшие аддоны»** (Interface `30300`).
4. Введите `/rc` в игре, чтобы открыть настройки, или `/rc wizard` для мастера
   настройки.

Настройка не требуется — аддон определяет спек и работает «из коробки».

## Возможности

### Ротация
- **Подсветка панели** с приоритетными цветами и стилями свечения (пульс /
  статика / вспышка / радуга), плюс палитры для дальтоников.
- **Окно иконок** с топ-рекомендациями, оверлеем кейбиндов, индикатором режима
  цели (S / A / Au) и причиной простоя.
- **Прогноз DPS в реальном времени** (`~5200 DPS`, факт и потери %) в бою.
- **Окно кулдаунов** (готовые первыми, настраиваемый минимум КД).
- **Окно прерываний**, реагирующее в момент начала каста цели.
- **Таймлайн боссов** из DBM / BigWigs (работает и без них): подсказки
  `Hold CD` / `Prepare` / `BURST` и авто-переключение режима цели по фазам.

### Обучение и подсказки
- **Пульс класса** — зелёный/жёлтый/красный индикатор качества исполнения.
- **Режим наставника** — объясняет ошибки после N подряд.
- **Режим экзамена** — без подсветки, только REC1 и отчёт по точности.
- **Режим обучения** — рекомендует на манекене и объясняет *почему*.
- **Адаптивная ротация** — `simple` / `normal` / `complex` по среднему илвлу.
- **Статистика обучения** — история точности / DPS (`/rc learning`).
- **Хаб наставника** (`/rc hub`) — статус/оценка, план КД, разбор боя
  (`/rc analyze`), симулятор (`/rc sim`), редактор APL (`/rc apl edit`),
  проверка талантов (`/rc talents`) и монитор здоровья группы.

### Автоматизация и кастомизация
- **Кастомный APL** — текстовый приоритетный список (`/rc apl import`),
  заменяющий ротацию; экспорт и шаринг одной строкой (`/rc apl share`).
- **Профили боссов** — переопределения по энкаунтеру (ICC / ToC / Ulduar / Naxx /
  RS).
- **Профили по спекам** и **импорт/экспорт текстом** (безопасный парсер, без
  выполнения кода).
- **PvP-режим** — ветка прерывание > контроль > бурст > выживание.
- **Помощь хилеру** — рекомендует лечение участнику с минимальным HP из наборов
  по классам, плюс монитор здоровья группы.
- **DPS для хил-спеков** — берёт DPS-ротацию класса во время лечения.
- **Темы** — цвет класса (по умолчанию), Dark, Light, High contrast; компактное
  окно; единый шрифт с режимом крупного текста.
- **Настройка панелей** (как в Dominos) — сетка с подсветкой, клик для
  настройки, привязка к сетке при перетаскивании.
- **Стили фона** (скруглённый / стекло / матовый), шрифт и тень заголовка,
  анимации окон.
- **Дополнительно** — панель DoT/дебаффов, счётчик врагов, предупреждения о
  переполнении ресурса, расовые кулдауны, таймер свинга, полосы таймлайна,
  отчёт боя (по умолчанию выключен, при включении — только на боссах).
- **Мастер настройки** и **подсказки** к каждому элементу.

## Как это устроено

```
RotationCore/                 ядро: движок, состояние, настройки, UI, локали
RotationCore_<Class>/         по одному LoadOnDemand-модулю на класс
  ├── <Class>.lua             способности, spell id, баффы/дебаффы, глифы, таланты
  └── Core.lua                симуляция приоритетов по спекам
```

Каждый класс регистрирует данные через небольшой API (`RegisterAbilityTable`,
`RegisterGlyphs`, `RegisterBuffs`, `RegisterTalentMap`, …). Ядро каждый кадр
прогоняет короткую симуляцию, чтобы выбрать следующее действие с учётом режима
цели, кулдаунов, ресурсов и длительности боя. Все spell id сверены с официальной
базой 3.3.5a.

## FAQ

**Аддон играет за меня?**
Нет. Он лишь подсвечивает следующую способность; каждую кнопку вы нажимаете сами.

**Работает без DBM/BigWigs?**
Да. Таймлайн деградирует мягко; DBM/BigWigs добавляют точные таймеры.

**Поддерживаются ли кастомные spell id приватных серверов?**
Вшитые данные рассчитаны на официальные id 3.3.5a. Для кастомных серверов
используйте APL (`/rc apl`) или переопределите id в модуле класса.

**Мои данные в безопасности?**
Настройки хранятся в `RotationCoreDB` (SavedVariables). Импорт профилей —
собственный парсер, без `loadstring` и выполнения кода.

**Почему нет какой-то способности?**
Сообщите её id из `https://wotlkdb.com/?spell=<id>` в
[bug report](https://github.com/Hijackery/RotationCore/issues/new/choose).

## Совместимость

- Interface **30300** (3.3.5a). Нет вызовов `C_*` / API 4.0+, нет Ace3, нет
  `loadstring` на пользовательском вводе.
- По одному LoadOnDemand-модулю на класс; внешних библиотек сверх вшитых
  `Libs/` нет.
- Локали: enUS/enGB (база), ruRU, deDE, frFR, esES/esMX, ptBR, itIT, koKR,
  zhCN, zhTW — все 12 официальных локалей WotLK 3.3.5a.
- **Статическая проверка:** `python3 RotationCore/verify.py` (парс, паритет
  локалей, версии, скан запрещённых API). В игре: `/rc selfcheck`.

## Разработка

См. [CONTRIBUTING.md](./CONTRIBUTING.md). Статические проверки (без клиента):

```bash
pip install -r requirements-dev.txt
python3 RotationCore/verify.py
```

CI запускает те же проверки на каждый push и pull request. Релизы
автоматизированы: запушьте тег `v<version>` — пайплайн проверит, соберёт zip и
опубликует GitHub Release.
