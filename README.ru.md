Приоритетный помощник ротации для **World of Warcraft 3.3.5a (WotLK)**, v1.0.0.

Аддон следит за вашей специализацией, талантами, ресурсами и целью, после чего
подсвечивает следующую способность. Модульная структура: небольшое ядро плюс
отдельный LoadOnDemand-модуль на каждый класс.

## Установка

1. Скопируйте папку `RotationCore` и нужные папки `RotationCore_<Class>` в
   `World of Warcraft/Interface/AddOns/`.
2. Включите «Загружать устаревшие аддоны» (Interface 30300).
3. `/rc` открывает окно настроек.

## Возможности

- **Подсветка ротации** на кнопках панели с приоритетными цветами и стилями
  свечения (пульс / статика / вспышка / радуга), плюс палитра для дальтоников
  (Display → Highlight).
- **Окно иконок** с топ-рекомендациями, оверлеем кейбиндов, индикатором режима
  цели (S / A / Au) и причиной простоя, когда делать нечего.
- **Прогноз DPS в реальном времени** над окном иконок (`~5200 DPS`, фактический
  DPS и потери %) в бою.
- **Пульс класса** — зелёный/жёлтый/красный индикатор качества исполнения
  (точность кастов, аптайм DoT, использование кулдаунов).
- **Окно кулдаунов** (сортировка «готовые первыми», настраиваемый минимум КД).
- **Окно прерываний**, срабатывающее в момент начала каста цели.
- **Таймлайн боссов** из DBM / BigWigs (работает и без них): подсказки
  `Hold CD` / `Prepare` / `BURST` и авто-переключение режима цели по фазам.
- **Кастомный APL** — текстовый приоритетный список (`/rc apl import`),
  заменяющий встроенную ротацию; экспорт и шаринг одной строкой через
  `/rc apl share`.
- **Режим экзамена** — без подсветки панели, только REC1, отчёт по точности.
- **Режим наставника** — объясняет ошибки после N подряд.
- **Адаптивная ротация** — `simple` / `normal` / `complex` выбирается
  автоматически по среднему уровню предметов.
- **Статистика обучения** — история точности / DPS по боям (`/rc learning`).
- **Профили боссов** — переопределение настроек по энкаунтеру (пресеты
  ICC/ToC/Ulduar/Naxx/RS).
- **Помощь хилеру** (`/rc` > вкладка Healer): рекомендует лечение для
  участника группы с минимальным HP из наборов лечений по классам; плюс
  монитор здоровья группы. Вкладка видна всем, но редактировать могут только
  хилер-классы.
- **Дополнительно** (Advanced): панель DoT/дебаффов с отметкой ключевых DoT,
  счётчик врагов, предупреждения о переполнении ресурса, расовые кулдауны,
  таймер свинга, полосы таймлайна и итоговый отчёт боя.
- **Темы**: цвет класса (по умолчанию), Dark, Light, High contrast; компактное
  окно иконок; единый шрифт окон с режимом крупного текста.
- **Настройка панелей** (как в Dominos): сетка с подсветкой; клик по окну —
  настройка, привязка к сетке при перетаскивании.
- **Стили фона** (скруглённый / матовый / стекло), кастомный шрифт и тень
  заголовка, стеклянные края слотов и анимации окон.
- **Хаб наставника** (`/rc hub`): статус/оценка, план кулдаунов, разбор боя
  (`/rc analyze`), история аналитики; **симулятор** (`/rc sim`), **редактор
  APL** (`/rc apl edit`), **проверка талантов** (`/rc talents`), **монитор
  здоровья группы**; публичный API (`DH:SetRecommendationCallback`).
- **Мастер настройки** для пошаговой конфигурации.
- **Подсказки к настройкам** для каждого элемента (чекбокс, слайдер, дропдаун,
  кнопка) с локализованной подстановкой.
- **Импорт / экспорт профилей** текстом (безопасный парсер, без выполнения
  кода) и **настройки по специализации**.
- **Режим обучения** — продолжает рекомендовать на манекене и объясняет
  *почему*.
- **DPS-ротация для хил-спеков** — берёт DPS-ротацию класса во время лечения.
- **PvP-режим** — приоритетная ветка прерывание > контроль > бурст > выживание.
- **Аналитика**: `/rc stats`, `/rc stats dps`, `/rc log`.
- **Локализация**: RU-покрытие интерфейса, подсказок и вывода `/rc <class>`
  (EN-фолбэк; паритет проверяется по всем 8 зеркалам).

## Горячие клавиши

| Бинд        | Действие           |
|-------------|--------------------|
| ALT-SHIFT-L | Режим обучения     |
| ALT-SHIFT-V | PvP-режим          |
| ALT-SHIFT-E | Режим экзамена     |

Настройте их, а также **Открыть настройки** и **Настройка панелей**, в
**Привязка клавиш > RotationCore**.

## Совместимость

- Interface **30300** (3.3.5a). Нет вызовов `C_*` / API 4.0+, нет Ace3, нет
  `loadstring` на пользовательском вводе (APL и профили используют
  безопасные собственные парсеры).
- По одному LoadOnDemand-модулю на класс (`RotationCore_<Class>`), внешних
  библиотек кроме вшитых `Libs/` нет.
- Локали: enUS/enGB (база), ruRU, deDE, frFR, esES/esMX (один файл на оба
  испанских варианта), ptBR, itIT, koKR, zhCN, zhTW — все 12 официальных локалей
  WotLK 3.3.5a.
- **Статическая проверка**: `python3 RotationCore/verify.py` (luaparser, паритет
  локалей, проверка версий, скан запрещённых API). Игровой аналог: `/rc selfcheck`.

## Разработка

Исходники аддона лежат в `RotationCore/`:

```
RotationCore/
├── RotationCore/               # ядро (движок, состояние, настройки, UI)
├── RotationCore_<Class>/       # по одному LoadOnDemand-модулю на класс
└── verify.py                   # статический верификационный харнесс
```

Статические проверки (WoW-клиент не нужен):

```bash
pip install luaparser
python3 RotationCore/verify.py
```

`verify.py` проверяет парсинг Lua, паритет ключей локалей во всех зеркалах,
согласованность версий между 11 файлами `.toc` и `DH.Version`, а также сканирует
запрещённые API (`C_*`, `loadstring`, …). CI запускает тот же скрипт на каждом
push и pull request.

### Как выпустить релиз

1. Поднимите `DH.Version` в `RotationCore/RotationCore/RotationCore.lua` и
   `## Version:` во всех 11 `.toc`-файлах (держите их одинаковыми — `verify.py`
   это проверяет).
2. Добавьте секцию в `CHANGELOG.md`.
3. Закоммитьте, затем поставьте тег и запушьте:

   ```bash
   git tag v1.0.0
   git push origin main v1.0.0
   ```

Workflow релиза повторно прогонит проверки, соберёт
`RotationCore-<version>.zip` (папки готовы к распаковке в `Interface/AddOns/`)
и опубликует GitHub Release с описанием из `CHANGELOG.md`.

### Контрибьютинг

- Идшники новых способностей должны быть сверены с базой 3.3.5a
  (`https://wotlkdb.com/?spell=<id>`).
- Каждая пользовательская строка должна быть локализована (EN-база + 8 файлов
  зеркал); `verify.py` падает при расхождении наборов ключей.
- Не вводите вызовы `C_*` / API 4.0+, `loadstring` и внешние зависимости
  сверх вшитых `Libs/`.
