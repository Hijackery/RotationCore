# RotationCore: чек-лист проверки в игре

Версия аддона: 1.0.0. Клиент: 3.3.5a.
Как читать: отмечай `[x]` при успехе, `[!]` при проблеме + коротко что не так.

## 0. Подготовка

- [ ] Аддон грузится без ошибок Lua (нет красного текста при входе).
- [ ] `/rc status` открывает диагностику, счётчики идут.
- [ ] Иконка на миникарте / `/rc` открывает окно настроек.
- [ ] Мастер настройки (wizard) проходит до конца и не требует ручных выборов.

## A. По функциям

### Определение специализации
- [ ] Смена спека (двойная специализация) переключает профиль автоматически.
- [ ] При смене спека цепочка приоритетов обновляется без /reload.
- [ ] Работает и на низком уровне / без части талантов.

### Режим цели (single / multi / cleave)
- [ ] Одна цель: очередь без AoE-способностей.
- [ ] 2–3 цели рядом: включаются multi-target способности.
- [ ] 4+ целей: включается cleave-очередь (DnD/Consecration/Blood Boil и т.п.).

### Кулдауны
- [ ] Большие КД (Avenging Wrath, Rapid Fire, Gargoyle...) появляются в очереди.
- [ ] При `cooldown_order = manual` КД из очереди уходят.
- [ ] При `auto_cooldowns = off` КД не предлагаются.
- [ ] Off-GCD способности (Kill Command, Blood Tap) не «съедают» GCD.

### DoT / болезни
- [ ] Болезни DK обновляются до спадения (не позже).
- [ ] Serpent Sting / Black Arrow / Explosive Trap поддерживаются.
- [ ] Проки (Sudden Doom, Lock and Load, Art of War, Rime) отрабатываются.

### Подготовка/спец-кейсы
- [ ] Paladin Ret: Art of War не «висит» постоянно (после правки 53488).
- [ ] Paladin Prot: Divine Storm появляется в AoE.
- [ ] DK Unholy: Howling Blast срабатывает в AoE (после правки).
- [ ] DK Blood: Blood Tap не предлагается, пока на КД.
- [ ] Hunter: Aimed Shot выдаётся мгновенно (не как каст 2.9 с).

### Подсветка / glow / таймеры
- [ ] Подсветка следующей способности совпадает со строкой очереди.
- [ ] Таймеры КД/дебафов идут корректно, не мигают.
- [ ] Тайл-статус (Status) отображает реальное состояние.

### Профили и сохранение
- [ ] Смена профиля (spec profile) грузит правильные настройки.
- [ ] Настройки сохраняются после /reload и перезахода.
- [ ] Позиция/размер окон восстанавливаются.

### Опции / Help / локализация
- [ ] Все вкладки без технического мусора (сырые ключи/флаги не видны).
- [ ] Подсказки (tooltips) и Help соответствуют настройкам.
- [ ] Вся видимая строка локализована (без английских утечек).

проверка в подземелье.

## C. По энкаунтерам (смоук-прогон)

### Подземелья (5 ппл, героик)
- [ ] Утгард-Пик (Utgarde Pinnacle): треш с плотной группой (AoE).
- [ ] Кузня Душ (Halls of Reflection): быстрые переключения цели.
- [ ] Цитадель Ледяной Короны (5 ппл): боссы + треш.
- [ ] Логово Ониксии / другие 5 ппл: утилити-прерывания.

### Рейды
- [ ] Наксрамас: Патчверк (single-target DPS-check).
- [ ] Наксрамас: Хейган / Лоскутик (движение + переключение целей).
- [ ] Обсидиановое святилище (Sartharion): переключение драконов (multi).
- [ ] Око вечности (Malygos): фазы, бурст.
- [ ] Ульдуар: Кологарн/Игнис (механика + движение).
- [ ] Ульдуар: Йогг-Сарон (переключение на щупальца: cleave).
- [ ] Испытание крестоносца: Борьба (наложение), Ануб'арак (adds).
- [ ] ЦЛК: Саурфанг (single), Леди (adds), Лана'тель (AoE треш).
- [ ] ЦЛК: Профессор / Королева / Лич: проверка переработки очереди в фазах.
- [ ] Рубиновое святилище: Халион: переключение фаз.

### Общие проверки на любом боссе
- [ ] Очередь не «залипает» на невыполнимой способности.
- [ ] При отсутствии ресурса (руны/мана/энергия) предложение корректно уходит вниз.
- [ ] В движении (каст на ходу) очередь не ломается.
- [ ] После смерти/воскрешения состояние восстанавливается.

## D. Нагрузка / стабильность

- [ ] Минут 10 боя без роста нагрузки (Status: тики/латентность стабильны).
- [ ] Нет ошибок Lua в бою.
- [ ] Отключение/включение аддона в бою не ломает интерфейс.
- [ ] Совместная работа с типичными аддонами (DBM, Bartender, ElvUI) без ошибок.
