## Platform checklist

### Warperia

1. Log in at https://warperia.com/.
2. Open https://warperia.com/upload-wotlk-addon/.
3. Fill name `RotationCore`, version `1.0.3`, category `Class`, description and
   the GitHub link.
4. Upload `RotationCore-1.0.3.zip` and the icon.
5. Add the changelog text above.
6. Wait for the file scan and moderation.
7. Keep the GitHub link attached so new releases are picked up.

### CurseForge

1. Sign in at https://authors.curseforge.com/.
2. Create a project for `World of Warcraft`, game version `3.3.5`.
3. Add icon, screenshots and the long description.
4. Upload `RotationCore-1.0.3.zip` with the changelog.
5. Set license to MIT and link the GitHub repository.

### WoWInterface

1. Open https://www.wowinterface.com/downloads/upload-update.php.
2. Choose `Upload New Interface/Addon`.
3. Select the WotLK/3.3.5 version if offered, add the zip, icon and description.
4. Submit for review.

### Felbite

1. Sign in at https://felbite.com/.
2. Use the addon submission form in the account area.
3. Provide the zip, icon, screenshots, source link and changelog.
4. Wait for approval.

### GitHub aggregators

Open a pull request that links the release:

- https://github.com/NoM0Re/WoW-3.3.5a-Addons
- https://github.com/TrinityCore/wow_335a_addons
- https://github.com/wowgaming/addon-archive

Use the release URL, not a copied zip.
