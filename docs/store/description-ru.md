# RotationCore

Помощник приоритетной ротации для World of Warcraft 3.3.5a (WotLK).

RotationCore следит за специализацией, талантами, ресурсами и целью, затем
подсвечивает следующую способность. Работает «из коробки», настройка не нужна.

**10 классов · 29 спеков · 12 языков**

## Что делает

Аддон учитывает текущий билд и состояние боя и показывает следующую способность
по приоритетному списку. Он ничего не кастует: каждую кнопку нажимает игрок.

Работает на любом приватном сервере с клиентом 3.3.5a, включая Warmane,
Project Epoch и другие реалмы WotLK.

## Возможности

- Подсветка панели действий с приоритетными цветами и стилями свечения.
- Окно иконок с топ-рекомендациями, кейбиндами и режимом цели.
- Прогноз DPS в реальном времени, факт и процент потерь.
- Окна кулдаунов и прерываний.
- Таймлайн боссов с DBM и BigWigs или без них.
- Режимы наставника, экзамена, обучения и PvP.
- Помощь хилеру и нанесение урона для хил-спеков.
- Своя ротация через текстовый приоритетный список.
- Профили боссов и профили по спекам.
- 12 языков: английский, русский, немецкий, французский, испанский,
  итальянский, португальский, корейский, китайский (упрощённый и традиционный).
- Мастер настройки, подсказки к каждому параметру и несколько тем интерфейса.

## Установка

1. Скачайте `RotationCore-1.0.3.zip` со страницы релизов.
2. Распакуйте в `World of Warcraft/Interface/AddOns/` так, чтобы папки легли как
   `AddOns/RotationCore` и `AddOns/RotationCore_<Class>`.
3. Включите **«Загружать устаревшие аддоны»** в списке аддонов.
4. Введите `/rc` в игре, чтобы открыть настройки, или `/rc wizard` для мастера
   настройки.

## Слэш-команды

| Команда | Действие |
|---|---|
| `/rc` | Открыть настройки |
| `/rc wizard` | Мастер настройки |
| `/rc toggle` | Включить или выключить аддон |
| `/rc spec <name>` | Выбрать билд |
| `/rc pause` | Заморозить рекомендации |
| `/rc train`, `/rc pvp`, `/rc exam`, `/rc mentor` | Режимы |
| `/rc apl` | Своя ротация |
| `/rc boss` | Профили боссов |
| `/rc hub` | Хаб наставника |
| `/rc selfcheck` | Самотест |

## FAQ

**Аддон играет за меня?**
Нет. Он лишь подсвечивает следующую способность, а каждую кнопку вы нажимаете
сами.

**Работает без DBM и BigWigs?**
Да. Таймлайн боссов работает сам по себе. DBM и BigWigs добавляют точные
таймеры.

**Мои данные в безопасности?**
Да. Настройки хранятся локально игрой и не покидают клиент.

**Работает на приватных серверах?**
Аддон рассчитан на стандартные данные 3.3.5a и работает на приватных серверах с
3.3.5a. Для кастомных способностей можно задать свою ротацию через `/rc apl`.
